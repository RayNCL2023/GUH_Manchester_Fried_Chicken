# 3D model shortlist (Sketchfab)

These were found by scout agents using the public Sketchfab API. Nothing has been downloaded yet.
The numbers come from the API, and **the models haven't been checked visually**.

- **License:** every model listed is downloadable and CC-BY unless flagged. CC-BY means each author must be credited.
- **Links:** `https://sketchfab.com/3d-models/<id>`
- **Installing a model:** put the GLB in `web/public/models/...` and list it in `MODEL_FILES` in `web/src/lib/hive/three/models.ts`. It gets scaled to its real-world length and placed on the road or in the sky automatically.
